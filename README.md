# WHO DIS - [https://gilabarreto.github.io/who-dis/](https://gilabarreto.github.io/who-dis/)

A modern-day take on the classic Guess Who game. Mark has picked a person and so have you. You ask him about faces, he asks you about something else. Guess his person before you run out of rounds.

Built with HTML, CSS and vanilla JavaScript. The 24 faces are pixel art drawn in code from the same traits the questions check.

# Getting started

1. Clone this repository onto your local device.
2. Open index.html.
3. Run `node test.js` to check the game logic.
